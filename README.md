# Suggested Learning Path

If you are starting DevOps from scratch, follow this order:

1. **Linux fundamentals**
2. **Networking fundamentals**
3. **Shell scripting**
4. **Git and GitHub**
5. **YAML**
6. **Python automation**
7. **Docker**
8. **Artifact repositories**
9. **Jenkins / CI/CD**
10. **AWS / Cloud fundamentals**
11. **Terraform**
12. **Ansible**
13. **Kubernetes**
14. **Helm**
15. **Prometheus**
16. **Grafana**
17. **DevSecOps**
18. **SRE**
19. **Production troubleshooting**
20. **End-to-end DevOps projects**

---

## ⭐ Recommended Approach

Don't just watch tutorials. For each major technology:

```text
Learn
  ↓
Practice
  ↓
Build a Project
  ↓
Troubleshoot
  ↓
Automate
  ↓
Deploy to Cloud
  ↓
Monitor
  ↓
Document
```

The goal is to move from **learning individual tools** to understanding how they work together in a **production-grade DevOps platform**.
